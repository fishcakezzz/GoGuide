# 电脑配件导购演示数据

## 数据范围与来源

在原有笔记本、显示器、扩展坞演示数据外，种子程序增加内存、显卡、显示器、硬盘、CPU、散热器、主板、机箱、键盘、耳机共 10 类、21 款商品。每款有 3 个**同型号同规格**的本地模拟报价，合计新增 63 个 SKU。商品名称参考 `tao.hooos.com` 可公开访问的第三方列表或商品页；每条商品保存 `source_url`，采集记录位于 [`data/public-listing-captures.json`](../data/public-listing-captures.json)。`scripts/collect-public-pc-listings.ps1` 可重新获取这些页面的标题、HTTP 状态和采集时间。

这些页面不是淘宝官方 API；部分链接是品类或搜索页，名称经过人工归一。没有获取或验证淘宝卖家报价、商品详情参数、实时库存或历史价格。代码中的 `source_kind=public_reference_demo` 表示“公开名称参考 + 本地演示”，不能理解为“淘宝真实商品数据”。直接淘宝搜索当前仅返回页面外壳，因此本项目没有绕过登录或反爬限制。

## 模拟字段与导购流程

`cmd/seed/pc_parts.go` 为每款商品构造规格、三档模拟报价与库存，用来演示同配置价差。三档报价不对应真实店铺，不承诺真实商家服务或促销。兼容性由 Go 基于 CPU/主板接口、内存代际、散热器接口、主板/机箱板型、显卡长度和散热器高度进行核验；缺少关键参数时返回 `UNKNOWN`。电源功率、BIOS 版本、内存 QVL 等尚未校验，生成的配件方案不能当作实际装机清单直接购买。

Agent 先用大模型提取用途、预算、品类和规格，再由 Go 检索与筛选商品，剪枝组合并计算总价、兼容性和同规格模拟报价范围。最多三套方案及核验理由交由大模型做文字比较；模型不能改写 SKU、金额、库存或兼容性结果。方案确认后仍由 Go 复核价格版本和库存。

## 价格曲线

`demo_price_snapshots` 为新增的每个 SKU 生成 30 个本地模拟价格点，`GET /v1/skus/{id}/price-trend` 返回 `data_kind=simulated_scenario` 和 `is_real_history=false`。页面明确写为模拟价格趋势。曲线中的“模拟促销场景”只是合成样本，不能用来推断淘宝历史低价、节假日促销概率或未来打折日期。取得有授权且可持续更新的真实历史报价后，才可设计真实价格分析与预测，并应单独评估质量。
