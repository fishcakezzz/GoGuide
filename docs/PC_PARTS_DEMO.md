# 电脑配件导购演示数据

## 数据范围与来源

在原有笔记本、显示器、扩展坞演示数据外，种子程序增加内存、显卡、显示器、硬盘、CPU、散热器、主板、机箱、键盘、耳机、电源共 11 类、26 款商品。每款有 3 个本地模拟报价，合计新增 78 个 SKU、总计 88 个 SKU。同款商品的三档报价规格相同；不同板卡品牌的 RTX 4060 共享芯片基准分，但具体板卡尺寸等字段独立。名称参考 `tao.hooos.com` 可公开访问的第三方列表或厂商规格页；每条商品保存 `source_url`，采集记录位于 [`data/public-listing-captures.json`](../data/public-listing-captures.json)。`scripts/collect-public-pc-listings.ps1` 获取页面标题、HTTP 状态和采集时间；个别厂商页面在脚本环境中不可访问，记录为失败，具体规格应以来源链接复核。

这些页面不是淘宝官方 API；部分链接是品类或搜索页，名称经过人工归一。没有获取或验证淘宝卖家报价、实时库存或历史价格。代码中的 `source_kind=public_reference_demo` 表示“公开名称参考 + 本地演示”，不能理解为“淘宝真实商品数据”。直接淘宝搜索当前仅返回页面外壳，因此本项目没有绕过登录或反爬限制。

## 模拟字段与导购流程

`cmd/seed/pc_parts.go` 为每款商品构造规格、三档模拟报价与库存，用来演示同配置价差。三档报价不对应真实店铺，不承诺真实商家服务或促销。兼容性由 Go 基于 CPU/主板接口、演示 BIOS CPU 支持列表、内存代际、主板/硬盘接口、散热器接口、主板/机箱板型、显卡长度、散热器高度及电源功率估算进行核验；缺少关键参数时返回 `UNKNOWN`。BIOS 支持列表、部分尺寸和功率是演示结构化字段，并未逐一核对真实销售批次；电源功率估算额外预留 100W 并乘 1.3，不检查实际线材。内存 QVL、供电接头与固件版本仍需人工核实，生成的配件方案不能当作实际装机清单直接购买。

Agent 先用大模型提取用途、预算、品类和规格，再由 Go 检索与筛选商品，剪枝组合并计算总价、兼容性、同规格模拟报价范围与 [参考分](SCORING.md)。最多三套方案及核验理由交由大模型做文字比较；模型不能改写 SKU、金额、库存、兼容性或分数。方案确认后仍由 Go 复核价格版本和库存版本。Worker 发现价格或库存版本变化，会把旧方案标为失效、生成新版本并记录变更原因；用户可以刷新会话查看，旧版确认返回 409。

## 价格曲线

`demo_price_snapshots` 为新增的每个 SKU 生成 30 个本地模拟价格点，`GET /v1/skus/{id}/price-trend` 返回 `data_kind=simulated_scenario` 和 `is_real_history=false`。页面明确写为模拟价格趋势。曲线中的“模拟促销场景”只是合成样本，不能用来推断淘宝历史低价、节假日促销概率或未来打折日期。取得有授权且可持续更新的真实历史报价后，才可设计真实价格分析与预测，并应单独评估质量。
